⇅เพิ่มข้อมูลเอง (วางจาก Excel)

แต่ละแถว: รหัสลูกค้า, งวดที่, จำนวนเงิน, วันที่, เดือน, พ.ศ. — คั่นด้วย Tab (ก็อปจาก Excel วางได้เลย) หนึ่งบรรทัดต่อหนึ่งแถว

⇄เทียบ/เพิ่มข้อมูลย้อนหลังเข้า Working Reference

วางข้อมูล (รหัสลูกค้า, งวดที่, จำนวนเงิน) ระบบจะเทียบกับ "รายการวันนี้" ในหน้าตรวจสอบ ว่าตรงกันไหม ขาดอะไร หรือมีอะไรผิดเพี้ยน (ดูแค่รหัส/งวด/จำนวนเงิน ไม่รวมค่าธรรมเนียม) — ถ้าตรงกันครบทุกแถว จะมีปุ่มให้บันทึกลง Working Reference โดยใช้วันที่ที่เลือกด้านล่างนี้

ย้ายลูกค้าไปคืนเครื่อง

พิมพ์รหัสลูกค้าแล้วกดค้นหา ระบบจะดึงประวัติทั้งหมดของลูกค้าคนนั้นมาให้ดูก่อน ยืนยันแล้วค่อยย้ายจริง (ลบออกจาก Working Reference ถาวร)

ตรวจ+ซ่อมรูปแบบงวดอัตโนมัติ

สแกนคอลัมน์ "งวดที่" ทั้งหมดใน Working Reference หาแถวที่รูปแบบผิดเพี้ยน (เช่น ถูกแปลงเป็นวันที่โดยไม่ตั้งใจ, ลืมใส่วงเล็บสถานะ) แล้วแก้ให้อัตโนมัติเท่าที่มั่นใจได้ ที่เหลือ flag ไว้ให้ตรวจเอง
